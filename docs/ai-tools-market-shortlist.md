# 热门 AI 工具精简清单

> 调研日期：2026-08-26。市场没有统一、跨品类的“热门”排名；以下是依据公开采用度、品牌知名度、产品更新活跃度，以及是否具备稳定 Web 入口做出的策展判断，不代表绝对名次。来源仅采用产品官网、官方文档和官方公告。

## Chat

| 工具                                   | 定位                                                              |
| -------------------------------------- | ----------------------------------------------------------------- |
| [ChatGPT](https://chatgpt.com/)        | 覆盖写作、推理、语音、图像、文件分析和通用工作流的综合 AI 助手。  |
| [Claude](https://claude.ai/)           | 擅长专业写作、长文档分析、复杂推理与可交互 Artifacts 的协作助手。 |
| [Gemini](https://gemini.google.com/)   | 深度连接 Google 搜索、Workspace 和 Android 生态的多模态助手。     |
| [DeepSeek](https://chat.deepseek.com/) | 以推理、编程和高性价比模型访问为特色的通用助手。                  |
| [Grok](https://grok.com/)              | 强调实时网页与 X 信息、语音、搜索和内容生成的一体化助手。         |

## Create

### Image

| 工具                                             | 定位                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| [Midjourney](https://www.midjourney.com/imagine) | 以视觉风格、审美质量、个性化和一致性创作为核心的图像工具。         |
| [Adobe Firefly](https://firefly.adobe.com/)      | 面向设计与商业制作，整合生成、编辑和 Adobe Creative Cloud 工作流。 |
| [Canva AI](https://www.canva.com/ai/)            | 面向个人和团队的一站式 AI 设计、图片编辑与内容生产入口。           |

### Video

| 工具                                | 定位                                                     |
| ----------------------------------- | -------------------------------------------------------- |
| [Runway](https://app.runwayml.com/) | 面向影视与创意制作的生成视频、素材编辑和视觉一致性平台。 |
| [Kling AI](https://kling.ai/app/)   | 覆盖文生视频、图生视频、多镜头和人物运动生成的视频平台。 |
| [HeyGen](https://www.heygen.com/)   | 主打数字人、脚本成片、配音、口型同步和多语言本地化。     |

## Code

| 工具                                              | 定位                                                       |
| ------------------------------------------------- | ---------------------------------------------------------- |
| [Cursor](https://cursor.com/)                     | 集智能补全、代码库理解和多步骤代理于一体的 AI 代码编辑器。 |
| [GitHub Copilot](https://github.com/copilot)      | 覆盖 IDE、GitHub、CLI、代码审查和云端代理的开发助手。      |
| [Codex](https://openai.com/codex/)                | 可在应用、IDE、终端和云端执行端到端工程任务的编程代理。    |
| [Replit Agent](https://replit.com/products/agent) | 从自然语言需求到应用构建、运行和部署的一体化云端开发工具。 |
| [Lovable](https://lovable.dev/dashboard)          | 面向创业者和产品团队的对话式全栈 Web 应用生成器。          |

Claude Code 也很活跃，但与 Claude 共享品牌和订阅关系；可作为第二批独立入口，并复用 Claude 的订阅 Provider。

## Platform

此处将 Platform 定义为“聚合模型、应用或 AI 基础能力的入口”，避免与 Code 混用。

| 工具                                     | 定位                                               |
| ---------------------------------------- | -------------------------------------------------- |
| [Hugging Face](https://huggingface.co/)  | 汇集开放模型、数据集和交互式应用的社区与托管平台。 |
| [Poe](https://poe.com/)                  | 聚合主流模型和用户自建 Bot 的消费级多模型平台。    |
| [OpenRouter](https://openrouter.ai/chat) | 通过统一账户和接口访问、比较及路由数百个 AI 模型。 |

## Research

| 工具                                                            | 定位                                                   |
| --------------------------------------------------------------- | ------------------------------------------------------ |
| [Perplexity](https://www.perplexity.ai/)                        | 实时检索网页并返回带引用答案的通用研究与答案引擎。     |
| [Gemini Notebook（NotebookLM）](https://notebooklm.google.com/) | 围绕用户资料进行有出处的问答、总结、音频和视频概览。   |
| [Elicit](https://elicit.com/)                                   | 面向科学研究的文献检索、筛选、数据提取和系统综述工具。 |
| [Consensus](https://consensus.app/)                             | 从同行评审论文中检索并综合证据的学术搜索引擎。         |

Google 已于 2026 年 7 月将 NotebookLM 更名为 [Gemini Notebook](https://blog.google/innovation-and-ai/products/gemini-notebook/notebooklm-gemini-notebook/)。SubLens 可显示新名称，同时保留 `notebooklm` 作为 alias，降低迁移期搜索成本。

## 可比性有限的官方信号

- [OpenAI](https://openai.com/index/scaling-ai-for-everyone/) 披露 ChatGPT 超过 9 亿周活跃用户；[Google](https://blog.google/innovation-and-ai/products/gemini-app/one-billion-monthly-users/) 披露 Gemini 超过 10 亿月活跃用户。
- [Google](https://blog.google/innovation-and-ai/products/gemini-notebook/notebooklm-gemini-notebook/) 披露 Gemini Notebook 已有超过 3000 万用户和 60 万个组织使用。
- [GitHub](https://github.com/features/copilot) 将 Copilot 称为其采用最广的 AI 开发工具，并披露数百万个人用户和数万企业客户。
- [Hugging Face Hub](https://huggingface.co/docs/hub/index) 官方文档披露超过 200 万模型、150 万数据集和 150 万个 Spaces。
- [OpenAI](https://openai.com/index/codex-for-every-role-tool-workflow/) 于 2026 年 6 月披露 Codex 每周用户超过 500 万。
- [Consensus](https://consensus.app/home/blog/university-access/) 披露超过 500 万用户、覆盖 10,000 多所大学；不同统计口径不能直接横向比较。
- [OpenRouter](https://openrouter.ai/blog/announcements/openrouter-is-joining-stripe/) 披露其社区超过 1000 万开发者和企业，每天处理超过 10 万亿 tokens。

## SubLens 首版推荐（14 个）

- **Chat（5）**：ChatGPT、Claude、Gemini、DeepSeek、Grok
- **Create（3）**：Midjourney、Runway、Kling AI
- **Code（3）**：Cursor、GitHub Copilot、Codex
- **Platform（2）**：Hugging Face、OpenRouter
- **Research（1）**：Gemini Notebook

该集合优先稳定 Web 入口、高频启动价值和订阅可追踪性。Canva AI、HeyGen、Lovable、Consensus 可作为第二批。

## 明确排除

根据当前产品决策，**v0、Sora、Windsurf、Adobe Firefly、Replit Agent、Poe、Elicit、Perplexity** 不纳入默认目录、搜索别名或分类入口，除非后续重新评估。
